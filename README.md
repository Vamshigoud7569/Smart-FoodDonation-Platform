# 🍲 Smart Food Donation Platform

A full-stack web application designed to reduce food wastage by connecting food donors with NGOs, charities, shelters, and individuals in need. The platform provides an efficient way to donate surplus food and ensure it reaches the right people before it expires.

## 📖 Overview

Millions of tons of food are wasted every year while many people struggle with hunger. The Smart Food Donation Platform bridges this gap by providing a centralized platform where donors can list excess food and receivers can request available donations.

The system enables seamless communication between donors and receivers, helping reduce food waste and promote social welfare.

---

## ✨ Features

### 👤 User Management
- Secure user registration and login
- Role-based access for Donors, Receivers, and Admins
- Profile management

### 🍛 Food Donation Management
- Create food donation listings
- Add food details, quantity, expiry date, and location
- Update or delete donation records

### 📍 Food Request System
- Browse available food donations
- Request food donations
- Accept or reject requests

### 📊 Dashboard
- Track donation activity
- View donation history
- Monitor platform impact

### 📱 Responsive Design
- Mobile-friendly interface
- User-friendly navigation

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/Vamshigoud7569/Smart-FoodDonation-Platform.git
cd Smart-FoodDonation-Platform
```

### Install Frontend Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm start
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Start Backend Server

```bash
npm run dev
```
